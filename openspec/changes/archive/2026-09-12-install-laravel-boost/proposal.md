# Install Laravel Boost and generate AGENTS.md

## Why

Per the project plan's L6 design, AI-onboarding for code-development guidance
(deterministic/predictable code, language best practices, paradigms,
maintainability) should be delegated to Laravel Boost, the official
first-party Laravel package for this purpose, rather than hand-maintained in
`AGENTS.md`. Today `AGENTS.md` only contains bootstrap instructions telling an
agent how to install PHP/Composer and Boost itself - it has no actual
code-development guidance yet.

## What Changes

- Add `laravel/boost` to `composer.json` require-dev and install it.
- Run `php artisan boost:install` to generate Boost's guidelines and MCP
  server configuration.
- `AGENTS.md` is regenerated by Boost, replacing the current
  bootstrap-only content with tailored code-development guidelines.
- Existing CI checks (test/analyse/cs-check/audit) continue to pass.

## Impact

- Affected specs: `agent-onboarding` (new capability)
- Affected code: `composer.json`, `composer.lock`, `AGENTS.md`, plus whatever
  config/MCP files `boost:install` places (e.g. `.ai/`, `.mcp.json`, or
  similar - determined by the installed Boost version).
- No application/domain logic, database, provider, or Filament changes.
- Scope note: this covers ONLY code-development guidance mechanics. L0-L5
  repo/environment/rules mechanics stay in `SETUP.md`/`CONTRIBUTING.md` and
  are out of scope.
